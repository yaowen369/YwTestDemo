## 使用与构建

测试安装包：[智慧车站 2.0 Debug APK](../app/build/outputs/apk/debug/智慧车站-2.0-debug.apk)。该文件与标准构建输出 `app-debug.apk` 内容一致，使用 Android Debug 签名。当前 Release 配置不加载个人签名材料，不提供正式发布签名包。

构建环境：Gradle 8.11.1、Android Gradle Plugin 8.0.1、Kotlin 1.7.20、Android SDK 33，采用本机 Android Studio 附带的 Java 21。最低声明 API 24，目标 API 33；这不代表全部系统版本均经实机验证。

在工程根目录执行：

```bash
./gradlew --no-daemon \
  -Dorg.gradle.java.home='/Applications/Android Studio.app/Contents/jbr/Contents/Home' \
  :app:assembleDebug :app:testDebugUnitTest :app:lintDebug
```

首次启动显示默认三张工单。要安排新一轮来单，在“我的工单”标题上 2 秒内连点 4 次，进入“工单调试”；选择默认三项、单项或多项及等待分钟，点“重新开始”。确认范围后检查通知、定时权限和系统后台限制；成功安排才清空当前工单并返回桌面。提前打开保持空列表和原计划。清除本地数据则取消计划及通知，并立即恢复默认三项。

## 持久化、权限与失败处理

| 项目 | 实现方式与边界 |
| --- | --- |
| 工单和分支材料 | 独立的 V2 私有快照。完整写入、同步及验证成功后才更新内存，不读取或迁移旧业务数据；损坏快照报错并保留原文件，不静默恢复三单。 |
| 草稿输入 | 文字变动落盘，离页、打开相机／相册、提交前再次保存；失败保留当前输入并提示。当前页面重建恢复分支和编辑内容。 |
| 照片 | 复制完整文件到 App 私有目录，完成读取校验和文件同步后才加入材料；按展示大小采样解码，应用 EXIF 方向。撤销期间保留副本。 |
| 重置和清理 | 先持久保存新状态，后清理不再被引用的照片；工单修订号使旧编辑器、相机结果失效。上传／提交读取当前快照，不持有可复活旧数据的任务引用。 |
| 提交 | 只校验并提交当前结果分支；当前照片全部成功且可读才完成，提交期间防连点；实际完成写入失败不会显示完成。提交期间查看照片，返回时进入只读完成记录。 |
| 来单计划 | 场景清单、数量、唯一标识、原始到期时刻和到达标记随快照保存。先以独立标识安排候选系统任务，再提交清空事务；失败取消候选并保留旧数据及旧计划，成功后取消旧任务。 |
| 系统定时 | `AlarmManager.setExactAndAllowWhileIdle`、显式广播接收器和不可变 PendingIntent；不依赖 Activity 倒计时。再次打开只校准原定时刻。强行停止、重启恢复不在本期必须范围。 |
| 开始前条件 | 分别检查 Android 13 通知许可、应用通知、通知类别、精确定时能力，以及系统报告的后台限制；不满足时保留数据并引导设置。普通省电优化不被一概当成必须关闭的条件。 |
| 通知 | “新工单提醒”高重要性类别；每批一条，正文数量取实际新增工单数。系统管理声音、振动、静音和勿扰；点击进入待处理，不覆盖已完成状态。全部完成或重置后移除旧通知。 |
| 幂等与补齐 | 新增工单和消费标记一并落盘，旧广播／重复广播不再建单或响铃。过期后打开 App 可补齐工单，不补响；该回补不视为后台提醒验收通过。 |
| 系统调用边界 | 本机事务与系统通知发布无法形成跨进程原子事务。为避免重复响铃，先持久化消费标记再发布；若进程恰在两步之间被终止，工单可保留但可能没有通知，不承诺此极窄窗口的必达。 |
| 速度设置 | 正常／快速只影响之后启动的本机上传和提交；退出调试页继续生效，新建业务 Activity 时恢复正常；不影响来单分钟。 |
| 备份与网络 | 不申请网络、广泛存储或相机权限；相机委托系统应用，照片使用系统授予的 URI 访问。关闭云备份和设备迁移中的业务文件备份。 |

## UI 对照证据

[原生页面预览](verification/station-v2/原生页面预览.png)由实际 Android View 树经桌面原生图形运行时绘制，包含应用内容区；**不是浏览器截图，也不是实机截图，不包含设备系统栏**。逐页图片保存在 [原生布局目录](verification/station-v2/原生布局/)。

已人工查看列表、详情、结果选择、材料、完成记录和工单调试图。按确认稿落实深蓝 `#0B192B`、卡片 `#15283E`、主操作 `#52E0C4`、左右 12dp、正文 16sp、辅助 14sp、标题 20sp、14dp 卡片圆角、至少 52dp 主按钮和至少 48dp 操作目标。列表问题／位置优先，开始后留详情，材料页底部提交，完成页不跳下一单。系统字体实际字形与浏览器略有差异，时间和编号使用本机实际数据。

布局自动检查覆盖 320dp／390dp × 100%／125%／150% 字体下的列表、详情、结果选择和材料页，检查文本区域、横向行宽和省略；大字体使用换行、滚动及照片入口纵排。隐藏调试延续同一视觉，但属于本轮新增实现，**未宣称已有用户验收**。

原生页面通过 `adjustResize` 和系统 IME 可见性处理输入：键盘展开时把提交操作放入表单滚动区，收起后恢复底部操作。这一实现仍需真实中文输入法、MC62 及普通手机窗口验证；布局图和自动断言不代替 A06／U01 的实机验收。
